### 1. Bug fix crítico en scoring (`run_batch.py`)

**Problema**: `_go_verdict()` usaba substring match con sets, pero "GO" matcheaba dentro de "NO_GO" → DataTube (NO-GO) ganaba el torneo sobre MineSafety (CONDITIONAL_GO).

**Fix**:
- Negatives checked first: `"NO_GO" in s` antes de `"GO" in s`
- `_composite_score`: NO-GO ahora penaliza -15 (antes 0); CONDITIONAL_GO ahora da +10 (antes 0)
- `_stage3_score`: mismo fix
- Resultado esperado: MineSafety (~52 pts) > DataTube (~33 pts) — orden correcto

```python
# run_batch.py:216
def _go_verdict(raw: Any) -> int:
    s = str(raw or "").upper().replace(" ", "_").replace("-", "_")
    if "NO_GO" in s or "DECLINE" in s or "ABORT" in s or s in ("FALSE", "NO"):
        return -1
    if "GO" in s or "YES" in s or "TRUE" in s or "PROCEED" in s:
        return 1
    return 0
```
